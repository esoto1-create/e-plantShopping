# 🌱 Paradise Nursery - Plant Shopping App

Este es mi proyecto final para el curso de React.  
Es una tienda online de plantas con carrito de compras, dos categorías de productos y gestión de estado con Redux Toolkit.

## Características principales

- Página de inicio con botón "Get Started".
- Listado de plantas divididas en aromáticas y medicinales.
- Cada planta muestra imagen, nombre, descripción y precio.
- Añadir al carrito con un solo clic.
- Carrito con ajuste de cantidades (+ / -), eliminación y cálculo automático del total.
- Página "Sobre nosotros" con información de la empresa.
